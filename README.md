# Omar AI Solver

موقع عربي متجاوب لرفع صورة ورقة أسئلة والحصول على حل مشروح باستخدام نموذج ذكاء اصطناعي يدعم تحليل الصور.

## المتطلبات

- Node.js 20 أو أحدث
- مفتاح API صالح من OpenAI مع إمكانية استخدام نموذج يدعم الصور
- اتصال بالإنترنت عند تشغيل ميزة الحل

## التشغيل محليًا

1. فك ضغط المشروع.
2. افتح الطرفية داخل مجلد المشروع.
3. ثبّت الحزم:

   ```bash
   npm install
   ```

4. انسخ `.env.example` إلى ملف جديد اسمه `.env`.
5. افتح `.env` وأضف مفتاحك بدل `put_your_api_key_here`:

   ```env
   OPENAI_API_KEY=your_real_api_key
   OPENAI_MODEL=gpt-4.1-mini
   PORT=3000
   ```

6. شغّل الموقع:

   ```bash
   npm start
   ```

7. افتح `http://localhost:3000` في المتصفح.

## النشر على الإنترنت

انشر المشروع على منصة استضافة تدعم Node.js، ثم أضف متغيرات البيئة `OPENAI_API_KEY` و`OPENAI_MODEL` و`PORT` في إعدادات الاستضافة. اربط نطاقًا إن أردت. لا ترفع ملف `.env` إلى GitHub ولا تضع مفتاح API في ملفات `public`.

## ما الذي يعمل؟

- واجهة عربية RTL بألوان أزرق وأبيض.
- اختيار صورة أو سحبها إلى منطقة الرفع.
- معاينة الصورة والتحقق من نوعها وحجمها.
- اختيار المادة ومستوى الشرح.
- إرسال الصورة إلى الخادم، ثم إلى نموذج رؤية، وعرض الإجابة.
- نسخ النتيجة وطباعتها.
- فحص بسيط لحالة الخادم عبر `GET /api/health`.

## ملاحظات مهمة قبل الاستخدام العام

- استخدم مفتاح API الخاص بك وراقب الاستهلاك والتكلفة وحدود الاستخدام.
- هذا النموذج الأولي لا يحتوي على حسابات مستخدمين أو حفظ دائم للنتائج أو لوحة إدارة.
- أضف تحديد معدل الطلبات (rate limiting)، وسجلات مراقبة مناسبة، وسياسة خصوصية قبل فتح الموقع للجمهور.
- نتائج الذكاء الاصطناعي قد تحتوي على أخطاء؛ راجع الإجابات، خصوصًا في الأسئلة غير الواضحة.
- تحقق من اسم النموذج المتاح لحسابك وإعدادات مزود API إذا لم يكن النموذج الافتراضي متاحًا.
